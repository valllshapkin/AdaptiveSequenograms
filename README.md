## Обзор (Overview)

**AdaptiveSequenograms** — это универсальный математический фреймворк для анализа спектрограмм, предназначенный для извлечения временных функций активации (**секвенограмм**) заданных эталонных паттернов. 

Основная ценность метода заключается в **адаптивной компенсации эха**: алгоритм одновременно находит моменты возникновения паттернов и «вслепую» подбирает профиль реверберации среды, специфичный для конкретной записи. Хотя метод был вдохновлен биоакустикой летучих мышей, его математическое ядро применимо к любой задаче поиска сигналов в условиях многолучевого распространения звука (гидроакустика, промышленная диагностика, сейсмология).

## Ключевые особенности

*   **Adaptive Echo Profiling:** Моделирование реверберации с использованием набора частотно-зависимых каузальных 1D-фильтров. Это позволяет учитывать физический закон поглощения звука (затухание высоких частот происходит быстрее).
*   **Sequenogram Extraction:** Точное определение моментов излучения паттернов даже при их сильном временном наложении.
*   **Physics-Informed ConvNMF:** Использование сверточной неотрицательной матричной факторизации с жесткими физическими ограничениями (каузальность эха, неотрицательность энергии).
*   **High Performance:** Реализация на базе **PyTorch** с использованием **FFT-сверток**, что позволяет обрабатывать спектрограммы объемом в миллионы фреймов за считанные минуты.
*   **Memory Efficient:** Интеграция эталонов через динамические срезы частот (slicing) без использования дорогостоящего zero-padding.

## Математическая модель

Наблюдаемая спектрограмма $S$ моделируется как:
$$S \approx \left( \sum_{k=1}^{K} H_k *_{t} W_k \right) *_{t} E$$

Где:
*   $W_k$: Известные эталонные паттерны (Templates).
*   $H_k$: Искомые функции активации (Sequenograms).
*   $E$: Искомое адаптивное окно эха (Frequency-dependent Echo).

Оптимизация проводится путем минимизации дивергенции Кульбака-Лейблера с $L_1$-регуляризацией для обеспечения разреженности секвенограмм.

## Установка и запуск (через Pixi)

Проект использует современный менеджер пакетов [Pixi](https://pixi.sh), который автоматически настраивает среду со всеми зависимостями (Python, PyTorch, CUDA).

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/yourusername/AdaptiveSequenograms.git
    cd AdaptiveSequenograms
    ```

2.  **Запустите демо-скрипт:**
    Этой команды достаточно, чтобы Pixi создал окружение и запустил синтетический тест:
    ```bash
    pixi run demo
    ```

## Структура проекта

*   `src/model.py`: Ядро системы — реализация FFT-сверток и архитектуры Blind Deconvolution.
*   `src/trainer.py`: Цикл обучения с использованием проецированного градиентного спуска.
*   `scripts/run_synthetic.py`: Генератор тестовых данных и визуализация результатов (Ground Truth vs Prediction).
*   `pixi.toml`: Конфигурация среды и зависимостей.

## Применение (Use Cases)

1.  **Биоакустика:** Анализ эхолокации животных в сложных акустических условиях (пещеры, леса, городская среда).
2.  **Промышленный мониторинг:** Поиск специфических звуковых паттернов работы оборудования на фоне цеховой реверберации.
3.  **Подводная акустика:** Деконволюция сигналов, искаженных многократными отражениями от поверхности и дна.
