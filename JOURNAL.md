# Project Journal: Adaptive Sequenograms

Этот документ служит дневником разработки и дорожной картой (roadmap) для проекта по извлечению секвенограмм с адаптивной деконволюцией эха.

## 🎯 Глобальная цель
Создать универсальный, быстрый и физически обоснованный алгоритм (на базе PyTorch), который берет "грязную" (реверберирующую) спектрограмму, набор эталонов и выдает:
1. Точное время срабатывания эталонов (секвенограммы).
2. Профиль затухания звука для данной конкретной записи (адаптивное эхо).

---

## ✅ Что уже сделано (Completed)

- [x] **Математическое обоснование:** Разработана гипотеза использования 1D частотно-зависимой свертки вместо 2D для сохранения физического смысла эталонов.
- [x] **Архитектура алгоритма:** 
  - Написаны FFT-свертки (`fft_conv1d`) для обработки массивов неограниченной длины без падения производительности $O(N \log N)$.
  - Реализована сборка чистой спектрограммы без паддинга (zero-padding avoidance) через частотные срезы (`f_start:f_end`).
- [x] **Функция потерь:** Реализована дивергенция Кульбака-Лейблера (KL-Div) + $L_1$-регуляризация (Sparsity) для формирования коротких спайков в секвенограммах.
- [x] **Проверка на синтетике (V&V):** Скрипт `run_synthetic.py` успешно доказал, что алгоритм может вслепую разделить сливающиеся сигналы.
- [x] **Компенсация фонового шума:** В модель внедрен обучаемый параметр `self.bg` (частотно-зависимый offset), который вбирает в себя постоянный фоновый шум, очищая секвенограммы от ложных активаций (убраны "горизонтальные полосы").
- [x] **Продвинутая визуализация:** Результаты сохраняются в высоком разрешении (`Results/synthetic_results.png`), добавлены сложные паттерны (chirps) и детальное физическое эхо.
- [x] **Инфраструктура проекта:** Настроена изолированная среда через `Pixi`, автоматический билд статьи через `Tectonic`.
- [x] **Черновик статьи (Draft):** Написан скелет научной статьи в LaTeX (`Article/main.tex`).
